2. 자료를 사용할 수 있는 권한

사용자는 적법하게 취득하고 사용할 권한이 있는 고객·업무 자료만 입력해야 합니다. 고객 개인정보와 민감정보를 처리·외부로 전송하는 데 필요한 설명, 동의 및 업무상 권한을 확인해야 합니다. 다른 사람의 계정, 문서, API 키를 무단으로 사용하거나 공유해서는 안 됩니다.

앱 및 참고자료의 이용이 원본 문서나 교육자료의 저작권을 이전하지 않습니다. 재배포·공개할 때는 해당 자료의 이용 범위를 확인해야 합니다.

3. 검수와 업무 판단

추출 내용, 자동 계산·정리 및 AI 결과는 사용자가 확인할 업무 보조 자료입니다. 문서 인식 오류, 입력 누락, 모델 오류 또는 자료의 시점 차이가 있을 수 있습니다. 고객에게 제공하기 전에 원문, 보험 약관, 공식 제도 자료 및 계산 조건과 대조해야 합니다.

앱은 보험금 지급 여부, 보험 가입·해지, 치료, 투자 또는 세무 판단을 확정하지 않습니다. 상담 피드백과 교육자료에 나온 표현·금리·세금·보장 예시는 개별 고객의 사실이나 현재 적용 규정으로 자동 인정되지 않습니다.

4. Google Drive와 외부 AI 서비스

Google Drive 연결은 사용자의 계정과 허용한 파일 범위에 적용됩니다. 동기화·휴지통 작업은 연결 권한, 인터넷 상태 및 Google 서비스에 따라 실패하거나 중단될 수 있으므로 앱의 저장 상태를 확인해야 합니다.

외부 AI API는 본인의 제공사 계정과 API 키로 이용합니다. 제공사의 이용약관, 데이터 처리 정책, 요금 및 사용량 제한이 적용됩니다. 제공사 비용은 사용자가 확인·관리하며, ChatGPT 등 대화형 서비스의 구독이 API 사용료를 포함한다고 가정해서는 안 됩니다. 이 앱은 외부 서비스의 요금·가용성·응답 정확성을 보장하지 않습니다.

5. 보관·삭제·백업

고객 자료는 PC별·Windows 사용자별로 보관됩니다. 앱을 다른 PC로 옮기는 것만으로 고객 자료와 연결이 자동 이전되지는 않습니다. 사용자는 저장 폴더와 백업을 관리하고, PC나 계정 접근 권한을 보호해야 합니다.

고객 삭제는 복원 가능한 휴지통 처리입니다. Drive의 고객 파일도 삭제할지 선택할 수 있으며, 선택한 경우 확인된 해당 고객 파일을 Drive 휴지통으로 옮깁니다. PC·Drive·외부 서비스의 완전 삭제는 각 저장 위치에서 별도로 관리해야 합니다.
