HOW IT WORKS

사용하는 사람마다, 자신의 업무 공간

  1. PC 앱 실행

    배포받은 ZIP의 압축을 모두 풀고 실행 파일을 엽니다. 업무 화면은 기본 브라우저에서 열립니다.

  2. 내 계정 연결

    Drive·연결 설정에서 본인 Google 계정으로 연결합니다. AI를 사용할 때는 본인의 AI 제공사와 API 키를 설정합니다.

  3. 업로드와 검수

    고객을 선택하고 자료를 업로드합니다. 원문과 추출 내용을 대조한 뒤 결과 파일을 생성합니다.

  4. 저장과 피드백

    결과를 내려받거나 본인 Drive에 저장합니다. AI 요약은 전송 동의 후 실행하며, 연결 없이 로컬 점검도 사용할 수 있습니다.

YOUR DATA

자료의 저장과 전송을 확인하세요.

고객 자료는 사용자의 PC에 보관됩니다. Drive 저장은 연결한 계정에 이루어지고, 외부 AI는 사용자가 선택해 실행한 내용만 처리합니다. 이 안내 사이트에 고객 자료를 업로드하는 기능은 없습니다.

사용 전에 알아두세요

Windows 10/11 64비트용 PC 앱입니다. Google Drive와 외부 AI를 사용하려면 인터넷 연결이 필요합니다. 외부 AI API는 제공사에 따라 비용이 발생할 수 있으며 ChatGPT 구독과 별개입니다.
