3. Google Drive 접근·사용·공유

배포판은 Google의 파일 단위 권한 drive.file을 요청합니다. 이 권한은 앱이 생성했거나 앱에 사용하도록 허용된 파일의 관리에 사용됩니다. 폴더와 파일의 메타데이터를 확인하고, 사용자 작업에 따라 업무 폴더를 만들거나 고객 자료·결과 파일을 저장하고 갱신합니다.

고객 삭제에서 Drive 삭제를 함께 선택한 경우에만, 앱이 해당 고객의 저장 이력으로 확인한 Drive 파일을 휴지통으로 옮깁니다. 이 작업은 Google 계정 소유자와 파일 연결을 확인하며, 다른 고객이나 참고 원본의 파일을 삭제하도록 설계되어 있지 않습니다.

앱은 Drive 파일을 자동으로 공개하거나 다른 사람에게 공유하지 않습니다. 사용자가 Google Drive에서 별도로 설정한 공유 권한은 Google의 설정에 따릅니다. 각 사용자의 Google 로그인 정보·자료가 배포자의 계정으로 전송되는 중앙 수집 기능은 없습니다.

범's AI 비서의 Google API로부터 받은 정보 사용 및 다른 앱으로의 전송은 Google API Services User Data Policy와 그 Limited Use 요건을 따릅니다. 배포자는 Google 사용자 데이터를 판매하거나 광고 타기팅, 신용 평가, 범용 AI 모델의 개발·학습에 사용하지 않습니다. Google API Services User Data Policy

4. 외부 AI 전송과 사용자 선택

로컬 자료 기반 점검은 외부 AI 호출 없이 PC에서 수행합니다. 외부 AI 기능은 사용자가 제공사와 본인의 API 키를 설정하고 해당 기능을 실행할 때 요청됩니다. 상담 AI 요약·피드백은 전송 동의가 있어야 실행됩니다.

상담 피드백 요청에는 직접 입력한 상담 내용, 선택한 고객 파일에서 추출한 텍스트, 관련 참고 기준 및 생성 지시가 포함됩니다. 자료 추출·분석을 위한 외부 AI 기능을 선택하면 해당 작업에 필요한 선택 자료의 내용도 제공사로 전송될 수 있습니다. 고객 자료가 들어 있으면 그 자료의 개인정보도 전송될 수 있습니다. API 키는 요청 인증에 사용됩니다.

제공사는 사용자가 선택한 OpenAI, Groq 또는 Google Gemini 등입니다. 제공사의 서버 위치, 처리·보관 기간 및 데이터 정책은 해당 제공사의 계정·API 설정과 약관에 따르며, 이 앱이 제어하거나 일괄 보장하지 않습니다. 앱은 외부 AI 서비스를 범용 모델 학습에 자료를 제공하는 목적으로 사용하지 않습니다. 사용자는 전송 자료를 검토하고 업무에 적합한 제공사와 데이터 사용 설정을 선택해야 합니다.

5. 저장과 보안

앱 자료는 Windows 사용자별 개인 앱 저장 폴더에 보관됩니다. Drive 인증 토큰과 앱 설정으로 저장한 AI API 키는 Windows의 사용자 계정 기반 보호 기능으로 암호화합니다. 고객 파일·업무 데이터 전체가 암호화되는 것은 아니므로 PC 로그인, 디스크 보호, 백업·공유 폴더 설정은 사용자가 관리해야 합니다.

Google 및 지원 AI 제공사와의 요청은 HTTPS로 전송합니다. 앱의 업무 화면은 해당 PC의 로컬 주소에서 실행됩니다. 배포자에게 고객 자료를 자동 전송하는 분석·통계 수집 기능은 포함하지 않습니다.

6. 보관 기간과 삭제

PC의 고객 자료·이력·결과는 사용자가 삭제할 때까지 보관됩니다. 앱의 고객 삭제는 복원할 수 있도록 고객을 휴지통으로 옮기는 처리이며, 원본 파일과 이력이 즉시 완전히 지워지지는 않습니다. Drive 파일도 삭제하도록 선택하면 해당 파일은 Drive 휴지통으로 옮겨집니다. Drive의 보관·최종 삭제는 Google 정책과 사용자 조작에 따릅니다.

완전 삭제가 필요한 경우 앱을 종료한 뒤 개인 앱 자료 폴더에서 해당 자료와 관련 기록·백업을 함께 삭제해야 합니다. 이 작업은 고객 휴지통 복원과 별개이며, 다른 고객 자료를 지우지 않도록 대상을 확인해야 합니다. Drive와 외부 AI 제공사에 이미 전송된 자료는 각 서비스에서 별도로 관리·삭제해야 합니다.

문의 내용은 지원 목적이 끝나면 삭제하는 것을 원칙으로 하며, 추가 문의 대응이나 관계 법령상 보관 사유가 있는 경우 필요한 범위에서 보관합니다. 문의에는 고객 문서, API 키, 인증 토큰을 보내지 마세요.
